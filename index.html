O que é Computação em Nuvem?

Computação em nuvem (cloud computing) é um modelo em que recursos de tecnologia — como servidores, armazenamento, bancos de dados e softwares — são disponibilizados pela internet, sob demanda, com pagamento conforme o uso.

Explicação

Em vez de comprar e manter computadores e servidores próprios (infraestrutura local), você pode “alugar” capacidade de processamento e serviços prontos de provedores de nuvem. Isso ajuda a reduzir custos iniciais, ganhar flexibilidade e escalar rapidamente quando a demanda aumenta.

Na prática, empresas e pessoas usam a nuvem para hospedar sites e aplicativos, salvar arquivos com segurança, executar análises de dados e automatizar tarefas. Os serviços normalmente oferecem alta disponibilidade, backups, monitoramento e recursos de segurança.

Exemplos de serviços em nuvem

  • Armazenamento: Google Drive, OneDrive, Dropbox, Amazon S3
  • Computação (servidores/VMs): Amazon EC2, Azure Virtual Machines, Google Compute Engine
  • Banco de dados gerenciado: Amazon RDS, Azure SQL Database, Google Cloud SQL
  • Hospedagem de aplicações: Vercel, Netlify, Azure App Service, Google App Engine
  • Contêineres e Kubernetes: Amazon EKS, Azure AKS, Google GKE
  • Funções serverless: AWS Lambda, Azure Functions, Google Cloud Functions
